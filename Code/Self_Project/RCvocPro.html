例句產生引擎

免金鑰 AI 模式的流程：① Pollinations AI 生成有深度的句子（匿名約每 15 秒只能請求 1 次，所以會自動等待）→ ② 失敗就去 Tatoeba 找真人寫的例句 → ③ 再失敗用 Free Dictionary → 中文翻譯缺的話交給 Google 翻譯。每個單字右邊會標出句子是從哪個來源來的。

例句難度

API Key 只會存在這台電腦瀏覽器的 localStorage，不會上傳到別的地方（只會送到你選的那家 AI）。不要把這個 HTML 檔連同瀏覽器資料給別人用。

語音

Windows 建議選「Microsoft ... Online (Natural)」的語音（Edge 瀏覽器才有），聽起來最自然。手機用 Chrome 就用系統語音。

資料備份

localStorage 是「綁在這個瀏覽器＋這個檔案位置」的。換瀏覽器、清除瀏覽資料、或把檔案搬到別的資料夾，資料就看不到了 → 記得定期匯出備份。
