📘 剪輯工作室・快速教學

1. 基本流程：素材分頁匯入檔案 → 按 ＋ 放到時間軸 → 在時間軸拖曳排列 → 加文字/字幕/特效 → 右上「匯出影片」。

2. 軌道（多軌時間軸）：越上面的軌道會蓋在越上層。主軌放影片、疊加軌放 Logo/子母畫面、文字軌放標題。

3. 關鍵幀（最重要！）：關鍵幀 = 在某個時間點「記住」位置、大小、旋轉、透明度。
例：在 0 秒按 ◆ 記錄「在左邊」，移動播放頭到 2 秒，把物件拖到右邊（會自動新增第 2 個關鍵幀），播放時電腦會自動算出中間的移動過程（這叫「插值」）。曲線可選「緩入緩出」讓動作更自然。

4. 轉場：選取第二段片段 → 轉場分頁點一種效果。兩段要在同一軌道、頭尾相接。

5. AI 去背：選取影片/圖片 → 右側「AI 去背」選「AI 人像」（適合人物），商品圖可用「AI 物件去背」，綠幕素材選「綠幕」。第一次會下載 AI 模型，需要網路。

6. 快捷鍵：空白 播放 ・ S 分割 ・ Delete 刪除 ・ K 關鍵幀 ・ ←→ 逐格（加 Shift 一秒）・ Ctrl+Z 復原 ・ Ctrl+D 複製 ・ 預覽畫面滾輪 = 縮放

7. 儲存：「儲存專案」會存成 .json（不含影片本身）。下次「開啟專案」後，再把同名素材匯入一次就會自動接回去。

8. 手機/平板：用 Chrome 或 Safari 開這個檔案即可；上方「素材 / 屬性」按鈕切換面板。
