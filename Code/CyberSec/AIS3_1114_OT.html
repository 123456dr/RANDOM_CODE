OT 工控資安 · 互動學習站

把第一天到第二天的所有內容整理成一條學習線，並在網頁裡直接讓你「模擬操作」——看封包、下指令、開關閥門、跑攻擊腳本，不用裝任何虛擬機就能先學會。

怎麼用這個網站
  • 左邊照順序往下走；每一節先講觀念，再給你一個可以動手的模擬練習。
  • 模擬畫面都是真的互動：你點、你打指令，畫面會照工控真實邏輯反應。
  • 這份模擬了真實操作的「判讀與邏輯」。真的要寫進履歷，最後仍建議用本機 Wireshark 開一次課程 pcap。
這門課在學 OT 資安：保護「會動的機器」（工廠的馬達、閥門、溫壓控制），而不是只保護資料。被駭的後果可能是爆炸、停產，不只是資料外洩。

1.1 OT 與 IT 的差別

先把世界觀調對：你熟悉的資安大多是 IT；工控是另一套優先順序。

比較IT 資安OT 資安
最重視機密性（資料不外洩）可用性（產線不能停）
被駭後果資料外洩、網站當機爆炸、停水停電、產品報廢
設備壽命3–5 年10–20 年，常是老系統
能不能隨便更新可以常更新修補停機成本高，常不敢更新
通訊協定HTTP、TLS…Modbus、DNP3… 多半沒有加密與驗證
為什麼對你（想當資安工程師）重要：台灣製造業、半導體、電力水資源很多，OT 資安人才稀缺、門檻高，是很好的差異化方向。

1.3 GRFICS 靶場

GRFICS 是一座「虛擬化工廠」，把 PLC、HMI、模擬裝置、攻擊機全裝進你電腦，讓你安全地練攻防，不會弄壞真設備。它模擬的是田納西伊士曼化學製程。

通訊流程（背起來，第二天會很有感）

化工廠物理模擬↔ 虛擬 IO—Modbus 502→ OpenPLC 控制器—Modbus 502→ HMI 螢幕

所有通訊都走 Modbus TCP · port 502，而且沒有身分驗證——這就是第二天要拆解與攻擊的對象。

v2 與 v3 的差別

GRFICSv2GRFICSv3
部署5 台 VirtualBox 虛擬機Docker，一條指令啟動
元件5 個7 個容器（多了防火牆、Caldera、IDS）
特點雙網段、ScadaBR全容器化、3D 視覺、整合 MITRE Caldera
GRFICSv3 多了「實體安全」關卡：便利貼帳密、沒鎖的 PLC 機櫃、私接路由器、磚頭擋住的門……提醒你資安不只網路，實體接觸常是最快的突破口。

1.4 Modbus 基礎（互動）

Modbus 是最老、最廣用的工控協定，走 port 502，沒有任何身分驗證——誰都能發指令，這就是它好攻擊的原因。先弄懂它的四種資料。

四種資料型態

一句話記：1 bit 就是開/關，16 bits 就是數值；Input 類只能讀，Output/Holding 類外部可寫。點下面切換看差別。

位置編號口訣：0x、1x 開頭是 bit（開關）；3x、4x 開頭是 16-bit 數值。1x/3x 是 Input 只能讀，0x/4x 是 Output/Holding 外部可寫。

1.5 Stuxnet 的啟示

Stuxnet 是人類史上第一個「目標是實體工廠」的惡意程式，2010 年被發現，摧毀了伊朗離心機。

它證明了一件事：純軟體的攻擊可以造成物理世界的真實破壞。這是 OT 資安這門學問誕生的原點，也是為什麼今天要用「虛擬化工廠」來練——因為真的練在真設備上，後果可能是災難。

2.1 Wireshark（封包模擬練習）

Wireshark 是抓封包工具。最重要觀念：它有兩個過濾器——Capture filter（抓之前，決定抓什麼，用空格語法 port 502）和 Display filter（抓之後，決定顯示什麼，用點語法 tcp.port == 502）。

模擬練習：讀懂一段工控流量

在過濾器輸入 modbus、arp、tcp.port == 502 或 ip.addr == 192.168.95.2，看清單變化；點任一封包看解碼。試著找出「有人在寫 coil（開關閥門）」的那一包。

 Wireshark 模擬器
No.SourceDestinationProtoInfo
↑ 點一個封包看它的解碼內容。

三步判讀法（面試也會問）

先認協定：看 Protocol 欄是不是 Modbus，或打 modbus 過濾。
判斷讀還是寫：看 Function Code。讀（FC 1/2/3/4）是正常監看；寫（FC 5/6/15/16）代表有人在動東西，是攻擊訊號。
看動了什麼：位址（第幾號點位）＋ 數值（ff00=ON／0000=OFF）。
常用 Display Filter意思
modbus只看 Modbus 流量
tcp.port == 502Modbus/TCP 的埠
tcp.flags.syn == 1 && tcp.flags.ack == 0只看連線開始的 SYN（看是不是掃描）
frame.time_delta > 1跟前一封包間隔超過 1 秒
其他武器：Follow TCP Stream（右鍵重組整條連線，打 CTF 常用）、Decode As（協定跑在非標準埠時強制解析）、tshark（指令列版，封包多時快）。

2.2 Modbus 攻防 · 實作模擬

這是整個課程的核心：對 PLC 發 Modbus 指令，讀出狀態、再寫值開關閥門，造成物理後果。下面是一座虛擬化工廠 + 指令終端機，你打的指令會真的改變閥門與壓力。

安全範圍

指令終端機（Kali 攻擊機）

試試看這些指令（打 help 看全部）。你讀/寫的結果會直接反映在上面的工廠：

指令作用
nmap --script modbus-discover -p 502 192.168.95.2掃描，確認有沒有 Modbus
mbtget -r1 -a 1 -n 4 192.168.95.2讀第 1~4 號 coil（看閥門狀態）
mbtget -w5 1 -a 1 192.168.95.2寫 coil：把第 1 號閥門開啟（0=關）
 sol@kali:~$
$
攻擊挑戰：想辦法讓壓力衝到紅色（爆炸風險）。提示：打開兩個進料閥、關掉排氣閥。用 mbtget -w5 1 -a 1、-a 2 開進料，mbtget -w5 0 -a 3 關排氣。這正是真實工控攻擊的核心：寫一個 coil，造成物理災難。
同樣的事也能用 Metasploit（use auxiliary/scanner/scada/modbusclient）或自己寫 pymodbus（client.write_coil(1, True, unit=1)）。工具不同，原理一樣。

2.3 中間人攻擊（ARP Spoofing / Ettercap）

除了直接對 PLC 下指令，攻擊者還能站在 HMI 和 PLC 中間，偷看甚至竄改封包。原理是 ARP 欺騙：騙兩台機器「我才是對方」，讓流量都經過你。

點按鈕看攻擊前後的流量路徑
步驟指令 / 說明
開啟轉送echo 1 > /proc/sys/net/ipv4/ip_forward
ARP 欺騙arpspoof -i ens33 192.168.95.5（騙 HMI）
竄改封包寫 Ettercap filter，把 ff 00 換成 00 00，編譯 etterfilter 後用 ettercap 執行
防禦角度：這種攻擊之所以成立，是因為 Modbus 沒有加密與驗證。偵測方法之一是用 Wireshark 找「同一個 IP 卻有不同 MAC」的異常。

2.4 GRASSMARLIN（資產盤點）

2.5 TRITON / TRISIS

TRITON（又叫 TRISIS）是 2017 年發現、目標是安全儀表系統 SIS 的真實工控惡意程式。SIS 是工廠最後一道安全關（出事時緊急停機），攻擊它代表有人想讓工廠在意外時「不會自動停下來」，極度危險。它走 Tristation 協定。

2.6 OT Caldera（自動化對手模擬）

MITRE 做的平台：把你前面手動打的攻擊寫成流程，按一下自動跑，還對應到 MITRE ATT&CK for ICS。先認得五個詞，再模擬跑一次 operation。

詞意思
Agent被 Caldera 控制、負責執行攻擊的機器
Ability一個具體攻擊動作（等於一個 ATT&CK 技術）
Adversary Profile一堆 Ability 組成的整段攻擊流程
Operation實際執行：選哪台 Agent 跑哪個 Profile
Fact預先設好的變數（例如 modbus port=502）供 Ability 使用
模擬：執行一個 Operation（自動化 Modbus 攻擊鏈）

2.7 延伸知識（課程內外都涵蓋）

MITRE ATT&CK for ICS

工控攻擊手法的「字典」，每個手法有編號。今天碰到的：
T0855 未授權指令、T0831 竄改控制、T0830 中間人、T0846 遠端系統探索、T0803 阻斷指令訊息。

tshark（指令列 Wireshark）

封包太多時用它批次過濾：
tshark -r x.pcap -Y "modbus" -T fields -e modbus.func_code -e modbus.data

GeoLite（看 IP 地理位置）

Wireshark 載入 .mmdb 後，封包會顯示國家/城市。過濾：ip.geoip.country_iso == "US"。事件調查很好用。

其他工控協定

Modbus 只是入門。延伸還有 DNP3（電力）、BACnet（樓宇）、Profinet、IEC-61850（變電所）。Caldera 的 OT 外掛都支援。
